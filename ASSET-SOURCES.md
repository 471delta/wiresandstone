# Public asset sources used in Wires & Stone v4

This revision deliberately uses public/open-licensed SVG assets rather than stock jewelry photography.

## Icon system

**Lucide 1.47.0** is used for interface icons (navigation, mail, external-link, gem, shield-check, code, copy, etc.). Lucide is distributed under the ISC license.

Source: https://lucide.dev/
Package: https://www.npmjs.com/package/lucide
